### 👨‍💻 About Me
I'm an independent software developer and the founder of **Miravolabs**, specializing in native Android applications and modern web services. I am passionate about crafting smooth user experiences with clean architectures. 

- 🔭 I’m currently developing **Love Partner** (a real-time device sync app) and maintaining **TextBot**.
- 📱 Specializing in: **Kotlin, Jetpack Compose, MVVM, and Material 3 Design**.
- 🌐 Backend & Web: Building microservices with **Python, Supabase, and Firebase**.
- 🎨 Design Preference: Absolutely in love with **Dark Mode, Glassmorphism, and seamless UI transitions**.
- ⚡ Fun fact: Started building production-ready mobile apps and backend services at the age of 15!
